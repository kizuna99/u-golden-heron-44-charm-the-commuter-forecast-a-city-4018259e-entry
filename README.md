A tiny Python program (`main.py`) that writes one line of weather forecast for the invented city of Puddlewick to `/output/entry.txt`: morning rain that clears by eight, sun strong enough to dry the market awnings, highs of 17 — and every puddle promoted to a mirror. Run it with `python3 main.py`; the output is a single UTF-8 line of at most 140 characters, byte-identical on every run.
